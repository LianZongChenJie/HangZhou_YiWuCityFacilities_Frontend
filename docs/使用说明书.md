# 配套费征收审批系统 操作使用说明书

（面向业务操作人员）

---

## 一、系统是做什么的

本系统用于办理建设项目**城市基础设施配套费的征收审批**业务。一笔业务（称为"办件"）从窗口受理登记开始，经过审核、签发、缴款确认，最后办结归档，全程在系统内流转。

每个办件会自动"流"到下一个岗位的待办列表里，您只需要每天登录系统，处理自己名下的待办即可。

---

## 二、登录系统

### 第一次使用前

请向系统管理员申请您的账号和密码，并确认已经开通了您的岗位权限。

### 登录步骤

1. 打开浏览器（推荐使用 Chrome 浏览器）；
2. 在地址栏输入系统网址（向管理员索取），回车打开；
3. 在登录页面输入**用户名**和**密码**；
4. 如希望下次自动填入账号密码，勾选**【记住我】**；
5. 点击**【登录】**按钮；
7. 验证通过后显示"正在加载系统中..."，稍等片刻即可进入系统。

进入系统后，默认打开**【待处理】**页面，这就是您的日常工作页面。

### 登录遇到问题怎么办

| 遇到的情况 | 处理办法 |
| --- | --- |
| 提示账号或密码错误 | 仔细核对后重试；仍然不行请联系管理员 |
| 忘记密码 | 联系管理员重置 |
| 登录后页面空白 | 检查网络连接，或换一台电脑/换 Chrome 浏览器再试 |

## 三、退出系统与修改密码

### 退出登录

1. 点击页面**右上角的头像**；
2. 在弹出的菜单中点击**【退出登录】**；
3. 在提示窗口点击**【确定】**，系统返回登录页。

> 建议：下班或离开电脑前请退出登录，避免他人误操作。

### 修改密码

1. 点击页面**右上角的头像**；
2. 点击**【重置密码】**；
3. 填写原密码和新密码，保存；
4. 下次登录使用新密码。

---

## 四、认识系统界面

登录成功后，您会看到：

- **左侧**：功能菜单，如"待处理""新建办件""办件查询""统计报表""系统管理"等（每人看到的菜单可能不同，由岗位决定）；
- **右上角**：您的头像和姓名（点头像可改密码、退出）；
- **中间主区域**：您正在办理的页面。

**【待处理】页面**是使用最多的页面，它按办理环节分成一排**页签**，例如"草稿待提交""待审核""待签发"……页签名字旁边如果有**红色数字**，表示该环节当前有几件待办。页面每 5 分钟自动刷新一次，也可以随时点击**【筛选】**按钮手动刷新。

---

## 五、一笔办件的完整旅程

一笔办件按下面的顺序流转，每个环节由不同岗位的人处理，办件处理完毕会自动进入下一环节对应人员的待办中：

**① 受理登记**（受理岗录入项目信息、算费）
→ **② 审核**（审核岗核对把关，可通过或退回）
→ **③ 签发**（签发岗开具缴款通知书；部分项目需先经建设科复核、过会）
→ **④ 缴款确认**（钱到账后核对登记）
→ **⑤ 办结归档**（办结岗登记领件、归档，归档后可打印回执单）

任何环节发现问题都可以**退回**，办件会回到受理岗修改后重新提交。整个过程一步接一步。

## 六、分岗位操作指南

> 提示：如果您的页面上看不到本指南中提到的某个页签或按钮，说明该功能未对您开通，请联系系统管理员。

### 6.1 受理岗

#### 新建一个办件

1. 点击左侧菜单**【新建办件】**；
2. 按表单从上到下填写，各部分说明如下：

| 表单部分 | 怎么填 |
| --- | --- |
| 前置材料核验 | 收到哪种纸质材料就勾选哪项（征收缴费表、工程规划许可证复印件、人防核定表复印件） |
| 业务标记 | ① 选择业务类型：初次 / 变更 / 竣备 / 免征；② 初次办理时选择项目细分：新建 / 改扩建 / 拆复建 / 旧城改造拆建；③ 项目证件未全的勾选"四证齐发"；④ 有免征的勾选"有免征"，并填写免征金额和政策依据 |
| 项目信息 | 填写项目名称、地块信息，选择资金来源和土地用途（土地用途可多选） |
| 建设单位 | 填写单位名称、联系人、联系电话 |
| 规划许可与面积 | 填写工程规划许可证号（四证齐发的项目可以先不填）、地上建筑面积、地下建筑面积、地上住宅面积、人防面积 |
| 配套费核算 | 金额由系统按面积**自动算出**（住宅每平方米 30 元、非住宅每平方米 80 元），一般不用动。拆复建项目需另填原项目信息和原缴金额，系统按差额计算 |
| 意见 | 填写受理意见（可简单记录受理情况） |

3. 填完后在页面底部选择：

   - **【保存草稿】**：暂时存起来以后再办（不检查必填项）；
   - **【提交审核】**：正式提交。系统会先检查必填项，再弹出确认窗口，点击**【确定】**即提交成功。

4. 提交成功后会弹出提示，您可以选**【继续新建】**马上录下一家，或选**【返回待处理】**回到待办列表。

#### 处理"草稿待提交"的办件

在**待处理 → 草稿待提交**页签中：

- 点**【修改】**：打开编辑页面继续补充完善，完成后再次保存或提交；
- 点**【提交审核】**：确认后直接送审，不用打开编辑页面；
- 点**【删除】**：作废此件，**删除后无法恢复**，请慎重。

#### 处理被退回的办件

1. 在**待处理 → 退回待修改**页签中，点击**【详情】**；
2. 在详情页下方"审批记录"里查看**退回意见**，了解退回原因；
3. 点击**【修改】**按退回意见更正信息；
4. 重新点击**【提交审核】**送审。

#### 四证齐发项目补录证号

四证齐发项目办结时若还没有工程规划许可证号，会出现在**待处理 → 待信息补录**页签：

1. 点击**【补录证号】**；
2. 在弹出窗口中填入工程规划许可证号；
3. 点击**【确定】**，办件即完成归档。

### 6.2 审核岗

1. 进入**待处理 → 待审核**页签（页签上有红色数字提示待办件数）；
2. 点击**【详情】**，仔细核对项目信息、面积和应收金额；
3. 处理方式二选一：

   - **审核通过**：点击**【审核通过】**→（可填写审核意见，也可以不填）→ 在确认窗口点击**【确定】**，办件自动送交签发环节；
   - 退回：点击**【退回】**→ **必须填写退回意见**（写清退回原因，方便受理岗修改）→ 确认后办件退回受理岗。

### 6.3 签发岗

#### 开具缴款通知书（签发）

1. 进入**待处理 → 待签发**页签；
2. 点击**【详情】**核对无误后，点击**【确认签发】**；
3. 在弹出窗口中选择**签发日期**（默认为当天，一般不用改），可填写意见；
4. 确认后，办件进入"待缴款"状态。

#### 核对缴款到账

缴款到账后：

1. 进入**待处理 → 待缴款**页签；
2. 点击**【确认到账】**；
3. 在弹出窗口中确认**到账日期**（默认当天）和**实际到账金额**（系统已自动填入应收金额，请按实际到账金额核对修改）；
4. 确认后办件进入"待办结"状态。

> 如发现缴费异常，可点击**【退回】**（需填写退回意见）。

### 6.4 建设科复核岗 / 过会岗

部分项目在签发前需要建设科先行把关，办件会出现在：

- **待签发（建设科复核）**页签：核对后点击**【复核通过】**（选择签发日期）或**【退回】**；
- **待签发（建设科过会）**页签：过会完成后点击**【过会通过】**（选择签发日期）或**【退回】**。

### 6.5 办结岗

1. 进入**待处理 → 待办结**页签；
2. 确认建设单位已领取纸质缴费表后，点击**【办结】**；
3. 在弹出窗口中填写**领取人姓名**（必填，即前来领件并签字的人）；
4. 确认后办件归档完毕。四证齐发且尚无证号的，办件会自动转给受理岗补录证号。

### 6.6 管理岗 / 领导查询

管理岗除办理业务外，还可以：

- **办件查询**：查询全部办件（见第七章）；
- **统计报表**：查看汇总数据、导出 Excel（见第八章）；
- **系统管理**：维护账号、岗位权限等（一般由专人负责）。

## 七、查询办件与打印回执

### 查询办件

1. 点击左侧菜单**【办件查询】**；
2. 输入查询条件（不用全填，填得越具体查得越准）：

   可按项目名称、建设单位、工程规划许可证号（需输入完整证号）、受理日期区间、业务类型、办件状态、应缴金额区间、办结/开票/到账时间、有无免征等条件组合查询；

3. 点击**【查询】**，列表显示结果；
4. 在结果中：

   - 点击**【详情】**（或直接**双击**某一行）查看办件全部信息；
   - 属于您职责范围内待处理的件，会出现**【办理】**按钮，点击直接去处理；
   - 已归档的办件会出现**【打印】**按钮。

### 打印回执单（审签单）

1. 在办件查询中找到**已归档**的办件，点击**【打印】**；
2. 系统新开一个窗口，显示《城市基础设施配套费征收缴费情况审签单》；
3. 核对内容无误后点击**【打印】**，在浏览器打印窗口中选择打印机打印；
4. 打印完成后点击**【关闭】**退出。

---

## 八、统计报表

1. 点击左侧菜单**【统计报表】**；
2. 系统默认显示**本月**的数据；也可以自行设置受理时间、办结/开票/到账时间、金额区间、办件状态等条件后点击**【筛选】**；
3. 页面上方的**汇总卡片**显示符合条件的件数、金额等总计数字；
4. 下方明细表列出每笔办件的单位、面积、应缴费用和各环节办理时间；
5. 需要留存或上报时，点击**【导出 Excel】**，选择保存位置即可获得 Excel 文件。

## 九、常见问题

**问：我看不到指南里说的某个页签或按钮？**
答：功能按岗位开通。请联系系统管理员，说明您的工作需要，由管理员为您开通。

**问：退回时点确定没反应？**
答：所有退回操作都必须先填写退回意见，填好后再点确定。

**问：系统算出的应缴金额不对？**
答：请先检查地上面积、地下面积、地上住宅面积、人防面积是否填写正确，改完面积后金额会自动重算。

**问：项目还没有工程规划许可证号，能提交吗？**
答：勾选"四证齐发"后，证号可以先不填。办件办结后由受理岗在"待信息补录"里补上证号即可。

**问：页面长时间没动，再操作时跳回登录页了？**
答：登录状态过期了，属于正常的安全保护。重新登录后会自动回到您之前操作的页面。

**问：列表数据好像不是最新的？**
答：点击**【筛选】**按钮手动刷新一下；系统每 5 分钟也会自动刷新一次。

**问：换了一台电脑，之前记住的密码没有了？**
答："记住我"只对当前电脑有效，属正常现象，手动输入账号密码登录即可。

1.2说明书目的
梳理全部业务规则、功能模块、审批流程、数据字段、权限、统计打印、特殊场景处理要求，作为开发、测试、验收的标准。
1.3术语
办结：业务流程全部审批完成，企业领单归档环节；
四证齐发：特殊办件场景，工程规划许可证暂未出具先行征收配套费；
工规证：建设工程规划许可证，系统核心字段；
规划复核/规划核实：规划核实，项目竣工备案阶段实测面积核算，用于多退少补；
局班子会：减免配套费内部审议流程；
竣备：工程项目竣工备案。
1.4系统核心业务目标
1.实现配套费全流程线上四级审批（受理→审核→签发→办结）；
2.内置配套费自动计算公式，替代线下Excel手工核算；
3.实现新建项目、扩建项目、改建项目、拆复建项目、旧城改造拆建项目、施工许可变更补缴、竣备多退少补、历史项目补缴及其他「」类项目关联管理，完成收费多退少补业务闭环；
4.流程待办提醒、项目关键信息补录提醒、权限分级管控。
二、业务基础规则
2.1收费计算标准
1.计价依据：建设工程规划许可证载明建筑面积。
2.收费单价：
-住宅建筑面积：30元/㎡
-非住宅建筑面积：80元/㎡
3.减免扣除项：人防配套面积不计征配套费；另有政策性减免项目单独走减免流程。
4.计算逻辑：应收总额=住宅面积×30+非住宅面积×80-政策减免金额。
 
地下住宅面积=（地下建筑面积-人防面积）*（地上住宅面积/地上建筑面积）
住宅面积=地下住宅面积+地上住宅面积
非住宅面积=【地上建筑面积+（地下建筑面积-人防面积）】-住宅面积
注：面积结果取得小数点后2位数，四舍五入。

2.2项目业务分类
2.2.1初次受理
1.适用场景：企业取得建设工程规划许可证，首次申报配套费；
2.项目细分：新建项目、扩建项目、改建项目、拆复建项目、旧城改造拆建项目；
3.前置材料：建设单位盖章的《义乌市城市基础设施配套费征收缴费表》（一式两份）、《建设工程规划许可证》复印件、《人防工程易地建设核实核定表》（如涉及人防面积）复印件；
4.核心凭证：工程规划许可证号。
2.2.2变更受理
1.触发条件：施工许可变更补缴、竣备多退少补、历史项目补缴；
2.业务逻辑：关联原初次受理单据，系统自动提取历史已缴金额，核算新增面积产生的补缴或退还费用；
2.2.3四证齐发办件
1.场景定义：项目暂未出具建设工程规划许可证，但需先行开具缴款通知书征收配套费；
2.处理规则：
-表单内置「四证齐发」勾选标记，工程规划许可证号字段允许“缺省”；
-系统定时推送补录待办提醒，操作人员后续拿到许可证后补录证号；
-补录权限开放给受理岗，补录完成后提交审批，再次进入“受理→审核→签发→办结”流程。
2.3费用减免业务规则
1.申请材料：单独配套费减免申请表、政策依据材料；
2.内部线下流程（系统可标记此状态）：窗口初审→业务科室复核→局班子会审议→市政府常务会审批；
3.系统处理要求：
-采用勾选字段标记减免类型、减免金额、政策依据；
-统计模块单独汇总全年减免总额、减免项目数量；
-减免审批未完成前，流程状态固定为「待线下审批」，无法进入缴款环节。
2.4办件流程状态
2.4.1 一般流程
1.待受理：企业提交纸质材料，窗口受理人员未提交下一步审核；
2.待审核：受理岗录入信息提交，等待审核人员处理；
3.待签发：审核通过，等待签发人员核算、在财政系统上开具缴款通知书，签发日为开票日；
4.待缴款：缴款通知书已打印发放，等待企业缴费；企业完成银行缴费，“签发”工作人员定时核对财政系统该项目的缴款到账信息，确认到账后，系统填入到账日期，点击下一步进入办结环节；
5.待办结盖章：费用确认到账，打印回执，企业签字领单，流程闭环；
2.4.2 特殊流程
1.待信息补录：四证齐发类办件，规划许可证号空缺待补；在一般流程办结后，再次转入受理角色，标记“四证齐发待二审”
2.减免审批：减免项目，等待政府线下会议审批的，在初次受理时，标记“待减免审批”，进入审批环节挂起，直至审批人员收到审批结果后，点击“审批同意”或者“驳回”修改。
三、系统功能模块详细需求
3.1办件受理模块
3.1.1基础录入字段
1.项目信息：项目名称、地块信息、资金来源（私营/政府/国有/集体/外资/其他「手动补充」）、土地用途（居住、住宅、商业、工业、教育、商务金融、城镇村道路、物流、物流仓储、其他「手动补充」，可多项勾选）；
2.建设单位信息：建设单位名称、联系人、联系电话；
3.规划许可信息：
-工程规划许可证号（核心关联字段，四证齐发场景可空，可后期补录）；
-建筑面积（地上建筑面积「」、地下建筑面积「」、住宅面积「」）注：缴款确认面积；
4.人防面积核定表：
-人防面积「」
-标记：新建/改扩建/拆复建/变更/竣备/历史项目补缴、四证齐发（勾选框）；
4.配套费金额字段（系统自动按照“2.1收费计算标准”的计算公式进行计算，支持人工复核修改）。
3.1.2数据导入功能
支持历史线下Excel配套费台账批量导入系统，用于历年数据统计；导入模板由系统导出，固定字段匹配。
3.2三级线上审批流程模块
3.2.1角色岗位
1.受理岗：窗口业务人员，负责录入项目信息、提交审核、四证齐发证号补录；
2.审核岗：业务复核人员，核对规划面积、计费标准、项目信息准确性，可退回修改；
3.签发岗：财务/收费负责人，每日核对财政系统缴费到账状态，确认到账后，填入到账时间并提交下一步；
4.办结岗：归档人员，缴费表盖章后打印办结回执。
3.2.2流程可视化展示
办件详情页展示流程进度条：
-已完成环节：绿色标识；
-当前待办环节：黄色高亮；
-未流转环节：灰色；
任意环节点击可查看对应人员操作记录。
3.3办结与打印管理模块
3.3.1打印模板
城市基础设施配套费征收缴费情况审签单-办结回执单：建设单位（个人）名称「」、项目名称「」、工程规划许可证号「」、建筑面积（住宅「」、非住宅「」、人防「」）、缴费金额「」、受理意见（资料齐全，申报建筑面积与工规证一致，缴费金额无误）、审核意见（申报材料符合要求，建筑面积与工规证一致，费用核算无误）、签发意见「」；缴费表领取人签字「」、领取时间「」。
3.3.2办结归档规则
1.确认费用到账后进入办结流程；
2.打印办结回执，企业签字领取申报表；
3.系统标记办件「已归档」，归档单据仍支持查询、打印；
4.变更、竣备单据归档后，仍通过规划许可证号关联至主项目台账。

3.4待办与提醒模块
1.全局右上角小红点待办消息提示；
2.待办分类：待审核、待签发、待缴款、待办结、待证号补录；
3.5查询检索模块
3.5.1多条件组合查询
支持单条件/多条件联合筛选：
工程规划许可证号（精准唯一查询）、建设单位名称、项目名称、办件日期区间、业务类型（初次/变更/竣备/减免）、办件状态、金额区间。
3.5.2查询结果功能
1.列表展示核心字段：项目名称、建设单位、工规证号、应缴金额、企业性质、土地用途勾选、当前流程状态、办结时间（含开票时间、到账时间）；
2.点击单条数据进入详情页，展示全流程审批记录、关联单据；
3.6统计报表模块
可选定受理时间区间、办结时间区间（含开票时间、到账时间）、应收费用金额区间，选办件清单，导出Excel，必要字段有：工程规划许可证号「」、建设单位「」、资金来源「」、建设项目名称「」、土地用途「」、住宅面积「」、非住宅面积「」、人防面积「」、应缴城市基础设施配套费「」、签发日期「」、缴费到账日期「」、建设单位联系人「」、联系电话「」。
3.7权限与数据修改模块
3.7.1修改权限管控
受理岗负责修改，并报审核岗进行审核，形成审批记录；
3.7.2账号角色权限隔离
-受理岗：仅录入、提交、补录、查看本人办件；
-审核/签发岗：查看全部办件、审批、修改数据、生成缴款审签单（办结时生成），直至办结；
-管理岗：全部查询、全部统计报表、查看减免台账、导出全量数据。

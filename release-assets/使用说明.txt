义乌市城市基础设施配套费征收审批系统（桌面原型）
================================================

【如何打开】
Mac：解压后双击「启动.command」
      若提示无法打开：右键 → 打开；或在「系统设置 → 隐私与安全性」允许。
Windows：解压后双击「启动.bat」
电脑需已安装 Python 3（Mac 一般自带；Windows 请安装时勾选 Add to PATH）。

启动后会自动打开浏览器：http://127.0.0.1:8080/
请保持黑色/白色命令行窗口不要关，关掉窗口系统即停止。

【演示账号】密码均为 123456
accept01  受理岗（登录进工作台，可新建办件）
review01  审核岗（登录进待审核）
issue01   签发岗（登录进待缴款）
close01   办结岗（登录进待办结）
admin01   管理岗（统计报表 / 权限管理）

登录页也可直接点岗位按钮。右上角可切换岗位。
头像菜单「恢复演示数据」可还原示例办件。

【建议演示路径】
受理新建并提交 → 切换审核岗通过 → 切换签发岗开票 → 确认到账 → 切换办结岗打印回执并归档。

【注意】
1. 不要把 web 文件夹单独挪走，须与「启动」脚本、serve.py 放在同一层。
2. 数据存在本机浏览器本地存储，换电脑或清缓存会回到示例数据。
3. 本包为前端展示原型，无真实后端、不对接财政系统。
